# Сайт-приглашение Ernar & Aidana

## Что внутри
- `index.html` — сам сайт
- `assets/photo1.jpg`, `photo2.jpg`, `photo3.jpg` — фото
- `assets/music.mp3` — ваша аудиозапись
- этот README

---

## Шаг 1. Создайте новый репозиторий на GitHub
1. Зайдите на https://github.com (или зарегистрируйтесь, если ещё нет аккаунта).
2. Нажмите зелёную кнопку **New** (или "+" вверху справа → **New repository**).
3. Название — любое, например `ernar-aidana-wedding`.
4. Оставьте **Public**.
5. Ничего не отмечайте (README/gitignore не добавляйте — они уже есть в архиве).
6. Нажмите **Create repository**.

## Шаг 2. Загрузите файлы одним разом
1. На странице пустого репозитория нажмите **uploading an existing file**.
2. Разархивируйте этот zip на компьютере — получится папка с файлами
   `index.html`, `assets`, `README.md` внутри.
3. Откройте эту папку, выделите **все файлы и папку `assets` целиком**
   (не саму внешнюю папку — а то, что внутри неё) и перетащите их в окно
   загрузки на GitHub.
4. Внизу нажмите **Commit changes**.

### Проверьте после загрузки
В репозитории в корне (без дополнительных вложенных папок) должно быть:
```
index.html
README.md
assets/
  photo1.jpg
  photo2.jpg
  photo3.jpg
  music.mp3
```
Откройте папку `assets` на GitHub и убедитесь, что там ровно эти 4 файла.

## Шаг 3. Подключите Vercel
1. Зайдите на https://vercel.com → **Sign Up** → **Continue with GitHub**.
2. На панели нажмите **Add New → Project**.
3. Найдите ваш репозиторий (`ernar-aidana-wedding`) → **Import**.
4. Настройки не трогайте (Framework Preset можно оставить "Other").
5. Нажмите **Deploy**. Через 20–30 секунд появится ссылка вида
   `https://ваш-проект.vercel.app`.

## Шаг 4. Впишите свой домен в код (один раз, важно для превью в мессенджерах)
Когда узнаете свою финальную ссылку (после Шага 3):
1. На GitHub откройте `index.html` → нажмите на иконку карандаша (Edit).
2. Найдите 3 строки, где написано `YOUR-DOMAIN.vercel.app`, и замените
   на ваш настоящий адрес (например `ernar-aidana-wedding.vercel.app`).
   Эти строки — самые первые в файле, под тегом `<head>`.
3. Внизу — **Commit changes**. Vercel передеплоит сайт автоматически.

Без этого шага сайт будет открываться нормально, но превью со ссылки
в WhatsApp/Telegram может не показывать фото.

## Если что-то не отображается
- **Не видно фото** — папка `assets` не загрузилась целиком или лежит не
  в корне репозитория (см. проверку после Шага 2).
- **Ошибка на Vercel при деплое** — скорее всего, вы случайно загрузили
  сам zip-файл вместо распакованных файлов. Удалите zip из репозитория,
  распакуйте его на компьютере и загрузите файлы (см. Шаг 2).
- **Музыка не играет** — это нормально при первом открытии: браузеры не
  разрешают звук без действия пользователя. Музыка включится при первом
  скролле/тапе по странице, либо кнопкой в левом верхнем углу.
- Если ссылка на сайт ведёт на вход в Vercel вместо самого сайта — значит,
  вы скопировали служебную ссылку деплоя вместо основной. Основная ссылка
  всегда указана на странице проекта в Vercel рядом с его названием.
